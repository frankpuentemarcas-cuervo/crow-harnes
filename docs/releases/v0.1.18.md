# Crow Harness 0.1.18 · Vista previa Markdown

Los archivos Markdown ahora se pueden leer con formato en el escritorio, sin perder la edición del texto original.

## Actualizar y usar

1. En Windows, usá **Buscar actualizaciones → Reiniciar y actualizar**, o instalá el `.exe` adjunto.
2. Abrí un archivo `.md`, `.MD`, `.markdown` o `.mdown` desde el explorador. Se muestra **Vista previa** por defecto.
3. Usá **Editar** para cambiar el texto y **Vista previa** para revisar el mismo borrador. Guardá antes de abrir enlaces a otra pestaña.

**No necesitás actualizar el servicio Linux para este cambio de Markdown.** El servicio remoto no cambió respecto de v0.1.17.

## Cambios

- Títulos, tablas GFM, listas, tareas, citas y bloques de código con formato.
- Tablas anchas con desplazamiento horizontal dentro del documento, sin desbordar el panel.
- El editor conserva su instancia al alternar con la vista previa; guardar mantiene la detección de conflictos por hash.
- Enlaces web en el navegador de Crow y archivos relativos dentro del proyecto. Con cambios pendientes, se solicita guardar primero para no perder el borrador.
- No se ejecuta HTML ni se cargan imágenes automáticamente. Documentos de más de 250.000 caracteres siguen disponibles en **Editar**, sin vista previa.

**Verificación:** 47 pruebas del cliente y chequeo de tipos. UI real probada con documento ficticio e IPC simulado, incluyendo panel de 375 px, guardado y protección de borradores. No se probó con archivos reales de un host del usuario.

**Seguridad de dependencias:** el escaneo conserva cuatro avisos preexistentes (dos moderados y dos altos); las nuevas librerías Markdown no agregaron avisos. Esas actualizaciones de seguridad quedan fuera de esta versión.
