# v0.1.50

Corrige el guardado cifrado del vínculo Android con la identidad automática de esta instalación de Crow. El rechazo del almacenamiento ya no se informa incorrectamente como un host desconectado.

Se verificó el flujo de vinculación, guardado, recuperación tras reiniciar, renovación mediante firma del dispositivo y revocación persistente. Esta corrección requiere actualizar Crow Windows; no requiere reinstalar Android ni reiniciar `crowd` en los hosts Linux.

La publicación incluye el instalador de Windows, el APK Android de prueba y los binarios Linux `crowd`.
