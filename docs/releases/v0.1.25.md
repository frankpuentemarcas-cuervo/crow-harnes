# Crow Harness 0.1.25 · Free LLM al iniciar

Crow comprueba Free LLM API después de resolver los diálogos de las llaves SSH y puede abrirlo automáticamente. **No requiere actualizar crowd Linux ni reiniciar agentes.**

## Actualizar y probar

1. Usá **Buscar actualizaciones → Reiniciar y actualizar**, o instalá el `.exe` de esta versión.
2. Con la clasificación por IA activada, abrí Crow y resolvé los diálogos SSH. Si la API de Free LLM ya responde, Crow no abre otra instancia.
3. Si la API está apagada, Crow intenta abrir Free LLM y muestra el resultado. Si no lo encuentra o el servidor sigue apagado, aparece un aviso con **Comprobar de nuevo** y **Configurar IA**.

## Configuración y alcance

- **Abrir Free LLM API al iniciar Crow** viene activado en los ajustes de IA. Desmarcalo para recibir sólo el aviso; con la IA desactivada no se comprueba ni se abre Free LLM.
- Se espera a resolver todos los diálogos SSH, no sólo el primero. Las llaves recordadas y los equipos sin hosts también permiten la comprobación; las reconexiones no repiten el lanzamiento.
- Se busca `FreeLLMAPI.exe` en sus carpetas habituales de instalación de Windows y se intenta abrir una sola vez por ejecución de Crow, sin shell ni argumentos. Si está instalado en otra carpeta, abrilo manualmente.
- Abrir Free LLM no garantiza que su servidor esté activo: Crow comprueba la API después. No modifica sus ajustes ni cierra Free LLM al salir de Crow.
- La comprobación usa GET local a `/v1/models`, sin claves ni conversaciones. Una API accesible **no confirma la clave ni los modelos**; para eso usá **Guardar y probar**, con tres ejemplos ficticios.

## Verificación

Pruebas unitarias, chequeo de tipos y QA React/Electron aislado: dos llaves SSH consecutivas, comprobación posterior al desbloqueo, reconexiones y aviso con reintento. Se mantienen las pruebas de sonido, diagnóstico cifrado y portapapeles.

El MCP experimental pendiente **no está incluido**. Más detalles en [Free LLM al iniciar](../free-llm-startup.md).
