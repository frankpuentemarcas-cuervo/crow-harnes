# v0.1.56

Mejora la continuidad de las terminales móviles cuando se reconecta la app o se renueva el transporte:

- Android conserva los transportes WebSocket por host y tolera cierres tardíos de streams ya finalizados.
- `crowd` y el relay agregan keepalive, reconexión más estable y diagnóstico de cierre sin registrar secretos ni datos de terminal.
- Windows y Android enrutan sesiones al host Linux asociado al QR y sincronizan los alias de terminal por usuario.
- Android mantiene las credenciales de acceso durante pausas de ciclo de vida y no reintenta escrituras inciertas.

La publicación contiene el instalador de Windows, el APK Android **debug de prueba** y binarios Linux `crowd`. Para activar cambios de `crowd`, actualizá cada host Linux con el instalador habitual; el instalador no reinicia el servicio si hay terminales activas o no puede comprobar su estado. El APK debug no es una versión de Google Play y la firma efímera de CI puede requerir reinstalar y volver a vincular. La compilación no reemplaza la validación en un teléfono real.
