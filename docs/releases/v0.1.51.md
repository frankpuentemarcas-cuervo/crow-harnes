# v0.1.51

- Reduce las consultas de identidad repetidas por proyecto y por bloque de salida al usar la identidad automática de instalación ya verificada en el túnel SSH activo. Las comprobaciones de configuración, propietario y permisos se mantienen.
- Regula la carga del historial para evitar desconexiones ante ráfagas de salida, conservando los límites de memoria.
- Android recupera la lectura de la terminal después de un fallo de envío o ajuste, sin reenviar comandos automáticamente. El ajuste muestra la causa del error y ambos botones indican cuándo están procesando una acción.

Actualizá Crow Windows y el APK Android para probar todas las mejoras. Esta corrección no requiere reiniciar `crowd` en los hosts Linux. El APK sigue siendo una compilación debug de prueba; la firma de CI puede requerir reinstalar y volver a vincular. Falta validar el rendimiento, envío y ajuste en el teléfono real.
