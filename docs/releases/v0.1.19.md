# Crow Harness 0.1.19 · Caché nativa de Claude

Métricas reportadas por Claude en cada terminal, en lugar del temporizador estimado desde el final del turno. Esta versión requiere actualizar **Windows y el servicio Linux**.

## Actualizar y probar

1. En Windows, usá **Buscar actualizaciones → Reiniciar y actualizar**, o instalá el `.exe` de esta versión.
2. En cada host Linux, como el usuario que utiliza Crow y sin `sudo`, ejecutá:

   ```sh
   bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/frankpuentemarcas-cuervo/crow-harnes/main/remote/install.sh | bash'
   ```

   Si hay terminales vivas, incluidas las suspendidas, el instalador no reinicia `crowd`. No fuerces el reinicio: esperá a terminar el trabajo y cerrá las sesiones remotas que ya no necesitás, luego repetí el comando. Cerrar solamente la pestaña no termina el proceso.
3. Comprobá `claude --version`: necesitás **2.1.251+** para estas métricas y **2.1.260+** para las causas del último fallo. Esta actualización de Crow no instala ni actualiza Claude.
4. Abrí una **terminal nueva** con Claude y los hooks de Crow habilitados. Tras una solicitud, revisá el indicador junto a esa terminal; hacé clic para consultar los detalles.

## Cambios

- Indicador por terminal y en la cabecera de la terminal seleccionada: estado, TTL reportado y cuenta regresiva.
- Detalle de tokens reutilizados, escritos y nuevos de la última solicitud; porcentaje acumulado de reutilización y causas conocidas del último fallo.
- **Notificaciones → Avisos de caché Claude**: habilitar/deshabilitar y anticipación de 15 segundos a 5 minutos (por defecto, 1 minuto).
- Un aviso silencioso por vencimiento y terminal, sin campana de revisión; se omite mientras el agente aparece trabajando. El aviso permite abrir la terminal correspondiente.
- Ausencia de campos, hooks o conexión se muestra como **Sin datos / Sin conexión**, sin inventar TTL. El reporte pertenece a la conversación principal, no a los subagentes.

## Privacidad y límites

Las métricas se conservan solo en RAM y viajan por el túnel SSH existente. No se envían a Free LLM, no se guarda el JSON completo de `statusLine` y no se mandan pings ni comandos automáticos al agente. Se conserva el comando `statusLine` de usuario/proyecto sin editar sus archivos; una configuración desactivada, ilegible o administrada puede impedir la captura.

**Vencer la caché no elimina la conversación** ni garantiza que el siguiente mensaje reutilice el mismo prefijo. Las alertas existentes de intervención, sonido y campana no cambian.

**Verificación previa:** 54 pruebas JavaScript, chequeo de tipos y pruebas Go en Windows; interfaz real con IPC ficticio. El workflow ejecuta también las pruebas del servicio y del instalador en Linux. La captura con Claude real, la conservación de un `statusLine` propio y las notificaciones nativas de Windows aún requieren validación en producción. No se reiniciaron servidores del usuario para publicar esta versión.

**Si algo falla:** desactivá los hooks de Crow para futuras terminales y abrí una sesión nueva; esto también desactiva los hooks de estado. Podés reinstalar v0.1.18 desde Releases; cualquier sustitución del servicio Linux debe hacerse sin sesiones remotas vivas. No se modifican las configuraciones originales de Claude.
