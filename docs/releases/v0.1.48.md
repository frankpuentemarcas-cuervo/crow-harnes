# v0.1.48

Corrige la creación de terminales en `crowd` cuando está habilitado el acceso individual: la identidad de esta instalación de Crow ya no se rechaza como revocada.

Para actualizar cada host Linux, ejecutá el instalador remoto como el usuario Linux que ejecuta `crowd`, sin `sudo`. Si hay terminales activas, el instalador deja el nuevo binario instalado y posterga el reinicio hasta volver a ejecutarlo sin sesiones activas.
