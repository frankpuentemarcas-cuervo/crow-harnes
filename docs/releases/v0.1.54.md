# v0.1.54

- Fixed Android Chat transcript capture for newly created sessions: `crowd` now accepts per-session hook credentials in both individual-access modes and for valid Crow installation owners.
- Hook credentials remain restricted to their matching session's event and cache writes; they do not grant general API access.
- Windows and Android have no functional source changes for this fix; this release rebuilds their versioned distribution artifacts alongside the updated Linux `crowd` binaries.

The Android APK is a debug test build, not a Google Play production release.
