# Crow Harness 0.1.31

Actualización de Windows con las mejoras de nombres de terminales, alertas inteligentes y conexión ERPNext. Usá **Buscar actualizaciones**, esperá la descarga automática y elegí **Reiniciar y actualizar**, o usá el instalador de esta release.

## Mejoras

- **Nombres de terminales:** se recargan al conectar los hosts después de abrir Crow. Una respuesta tardía no reemplaza un nombre recién editado ni muestra nombres fuera de los permisos actuales.
- **Alertas inteligentes:** el clasificador contempla pedidos actuales de autorización o acciones en otras sesiones, aunque la respuesta también informe progreso. Las citas resueltas y los pedidos futuros no cuentan como una acción actual. La prueba de Free LLM usa seis ejemplos ficticios.
- **Diagnóstico de alertas:** diferencia eventos que llegaron atrasados, espera excesiva en la cola local, pérdida de vigencia y fecha inválida. Muestra antigüedad al recibir el evento y posibles diferencias de reloj; no atribuye todo a la cola ni recomienda actualizar Linux sin evidencia.
- **ERPNext:** la prueba y la consulta usan exclusivamente `Task` con `status = Open`. El catálogo descarga metadatos, no descripciones; el detalle se lee al abrirlo, clasificar o revisar una autorización. Se conserva la verificación del texto completo antes del despacho.
- **Guardado ERP:** no permite probar credenciales anteriores mientras hay cambios sin guardar. Si guardar falla, conserva los campos para reintentar. La rotación exige API Key y API Secret juntas y conserva la configuración anterior si falla la escritura segura.

## Validación

- 248 pruebas unitarias, revisión de tipos y comprobación de diferencias.
- Pruebas aisladas de Electron: teclado/copiar-pegar, sonido/diagnóstico, arranque de Free LLM, catálogo ERP y nombres tras reconectar. No equivalen a pruebas de sonido físico ni a probar todos los modelos reales.
- Consulta ERP real de sólo lectura: 119 Tasks abiertas en dos páginas, 20.822 bytes; lectura de detalle e identidad verificadas. No se modificó el ERP ni se publicaron credenciales o contenido empresarial.

Esta release no cambia el código de `crowd` Linux: las correcciones son del cliente Windows. El historial de despachos se conserva; las tarjetas históricas fuera de `Open` quedan obsoletas y no habilitan nuevos envíos.

## Android companion: APK debug de prueba

- Se incluye `Crow-Companion-0.1.0-debug.apk` y su SHA-256. No es una versión de producción ni de Google Play.
- La firma debug de CI es efímera: otra compilación puede exigir desinstalar/reinstalar, perder los vínculos locales y emparejar de nuevo.
- Requiere Crow abierto en Windows, acceso individual habilitado y permisos explícitos por dispositivo/proyecto.
- No se validó esta release en un teléfono real; siguen pendientes las pruebas de cámara, teclado/IME, TLS, Keystore y conexión LAN/remota.
