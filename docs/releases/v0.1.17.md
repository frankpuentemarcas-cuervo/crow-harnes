# Crow Harness 0.1.17 · Alertas inteligentes

Clasificación semántica opcional mediante Free LLM: las peticiones de intervención generan sonido y campana; los avisos informativos o de progreso quedan sin sonido.

## Activar

1. Actualizá Crow en Windows con **Buscar actualizaciones → Reiniciar y actualizar** o instalá el `.exe` adjunto.
2. Actualizá `crowd` en cada Linux desde una **SSH externa**, cuando no haya terminales vivas ni suspendidas:

   ```bash
   bash -o pipefail -c 'curl -fsSL https://raw.githubusercontent.com/frankpuentemarcas-cuervo/crow-harnes/main/remote/install.sh | bash'
   ```

   El instalador no reinicia si detecta sesiones activas o no puede comprobarlas. No fuerces el reinicio: podría terminar sus procesos.
3. Mantené Free LLM abierto en Windows. En **Notificaciones → Configurar IA · Free LLM**, ingresá `http://127.0.0.1:31415/v1`, modelo `auto` y tu clave unificada. **Guardar y probar** valida tres ejemplos ficticios. Activá la clasificación por IA y guardá.
4. Iniciá una terminal de Claude Code o Codex con hooks administrados y verificá una petición de aprobación real.

## Cambios

- Clave cifrada en Windows, sin devolverla a la interfaz ni incluirla en los mensajes al modelo.
- Solo se analiza la última respuesta final. El texto no se guarda en el historial de alertas; los logs de terminal existentes no cambian.
- Fallas de API, cupo, texto ausente/truncado o clasificación incierta generan una **Revisión preventiva** con el motivo.
- Clic en la terminal reconoce incluso un análisis pendiente; su campana no reaparece al completarse.
- Corregidos pedidos de autorización en español en el clasificador local, usado cuando la IA está desactivada.

**Privacidad:** Free LLM local puede enviar respuestas a los proveedores de tu cadena. Activar esta opción autoriza ese envío; configurá una cadena adecuada para tus datos. `auto` respeta tu cadena; `auto:fast` prioriza velocidad entre modelos habilitados.
