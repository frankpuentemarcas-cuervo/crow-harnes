# v0.1.55

Actualizá Windows, Android y `crowd` juntos para probar estas mejoras del chat.

- Chat consulta la última respuesta al abrirse o volver a primer plano, y actualiza el historial con señales del agente sin esperar el sondeo periódico.
- El mensaje aparece inmediatamente con estados separados de envío, recepción confirmada por la terminal y actividad del agente. Los envíos inciertos nunca se repiten automáticamente.
- Un estado de agente desconocido ya no bloquea una terminal autorizada; el compositor sigue disponible para preparar el siguiente mensaje mientras el agente trabaja.
- Android reutiliza conexiones TLS/relay por perfil y separa lecturas de envíos para reducir esperas evitables.
- Windows espera la confirmación de escritura del PTY en `crowd`, en lugar de confirmar solamente una trama WebSocket encolada.
- Claude recupera el último texto disponible al iniciar o reanudar con hooks actualizados, usando únicamente el transcript de esa sesión. Los agentes ya ejecutándose pueden requerir un inicio o reanudación controlados para activar los nuevos hooks.

Las respuestas se incorporan por turno completado, no token por token. Las pruebas automatizadas y visuales no sustituyen la validación de latencia en un teléfono físico.

El APK publicado es debug para pruebas, no una versión de Google Play. La firma debug efímera de CI puede exigir reinstalar y volver a vincular el dispositivo.
