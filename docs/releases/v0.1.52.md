# v0.1.52

- Android incorpora una vista **Chat** separada de **Terminal**, con historial de conversación y scroll táctil natural. Cambiar de vista conserva la misma sesión y su salida; el stream de terminal se pausa mientras queda oculto y se reanuda al volver.
- Los controles de terminal se agrupan en un panel plegable para dejar más espacio al contenido. El desplazamiento por historial se habilita cuando xterm conserva scrollback y avisa cuando una pantalla interactiva no puede recuperar contenido anterior.
- `crowd` registra el historial de Chat de forma acotada, entrega streams Chat sin volcar salida PTY y corrige la captura de turnos Codex. El borrado de sesiones puede reanudarse de forma segura tras fallos de limpieza.

Actualizá Crow Harness para Windows, instalá el APK Android y actualizá `crowd` en cada host Linux con el comando de instalación de un paso del README. Si hay sesiones activas, el instalador Linux actualiza el binario sin reiniciar `crowd`; volvé a ejecutar el mismo comando cuando las sesiones hayan terminado para activar la versión nueva sin interrumpir agentes.

El APK es una compilación **debug de prueba**, no una versión de Google Play. La firma de CI puede cambiar y requerir desinstalar/reinstalar y volver a vincular. La publicación no reemplaza la prueba de extremo a extremo en un teléfono real.
